# @odinscode/carbide-home

Home components of [Carbide UI](https://github.com/odinscode-dev/carbide-ui) for React 19: HomeShell, navigation and a dashboard for home applications.

```bash
npm install @odinscode/carbide-token @odinscode/carbide-core @odinscode/carbide-home react react-dom
```

Examples are in the Storybook.
