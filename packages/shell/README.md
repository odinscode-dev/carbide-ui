# @odinscode/carbide-shell

Page shells of [Carbide UI](https://github.com/odinscode-dev/carbide-ui) for React 19: AdminShell for administration, BoardShell for control rooms, FieldShell for work in the field, and list and object pages.

```bash
npm install @odinscode/carbide-token @odinscode/carbide-core @odinscode/carbide-shell react react-dom
```

Examples for every shell are in the Storybook.
