# @odinscode/carbide-token

Design tokens of [Carbide UI](https://github.com/odinscode-dev/carbide-ui): colors, density, spacing, typography, motion and status colors as CSS custom properties, in a light and a dark theme. The package also contains the Carbide Sans, Display and Mono typefaces (SIL Open Font License 1.1).

```bash
npm install @odinscode/carbide-token
```

```ts
import "@odinscode/carbide-token/css/tokens.css";
```

Without a setting, the theme follows the operating system. Set `data-theme="light"` or `"dark"` and `data-density="compact"`, `"dense"` or `"large"` on any element to choose.
